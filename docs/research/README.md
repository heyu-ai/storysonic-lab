# Research — 研究與實驗

收錄 Podcast 調查、故事風格與語音分析、資料取得實驗及技術評估。研究文件保留觀察、推論與限制；需要架構裁決的結論另以 [ADR](../adr/README.md) 記錄，需要功能落地則建立 [OpenSpec change](../openspec/README.md)。

## 目錄與命名

- 單篇筆記使用 `YYYY-MM-DD-topic.md`。
- 含資料、圖表或可分享成果的研究使用 `YYYY-MM-DD-topic/`，以該目錄的 `README.md` 為入口。
- 每份研究標示查核日期、研究問題、來源、方法、結果、限制及尚未完成的部分。
- 報告、HTML、必要的 CSV 與驗證摘要可以納入 Git；原始音檔及大型工作集放在已忽略的 repo 根目錄 `data/` 或 `outputs/`。
- HTML 應可獨立分享，避免依賴作者電腦上的絕對路徑；原始素材的授權狀態需獨立記錄。
