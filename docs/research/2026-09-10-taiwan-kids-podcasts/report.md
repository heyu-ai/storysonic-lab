## 文字稿：有哪些來源

**公開 RSS：**10 個 feed 均未找到 `podcast:transcript` 或其他名為 transcript 的節點。這只表示沒有透過這類標籤直接提供逐字稿檔，不代表所有官網、單集說明和會員區都沒有文字資料。

**發布者自己提供的文字：**《聽故事學英文》的部分單集有可用素材。例如 [Ep232](https://open.firstory.me/story/cmo7a8mj90o5j01vqca2uaulv) 在 RSS 單集說明直接附新聞英文全文；[Ep243](https://open.firstory.me/story/cmsjwsnb71iqr01vicz80bkqf) 則說明年費會員可取得英文全文故事本 PDF，公開音訊是 7 分鐘試聽。英文全文、學習單或故事 PDF 未必包含節目所有中英對話，不能直接標成完整逐字稿。會員檔案本次未取得。

**豬探長官方文字稿：**本次公開 RSS 與官方介紹中未找到完整劇本／逐字稿下載入口。官網內容以單集故事簡介為主，簡介不能替代逐字稿。若需要經校對原稿，可向製作單位洽詢原始劇本、現成字幕或研究授權；[官方頁](https://detectivepig.firstory.io/)列有合作聯絡方式。

**Tapesearch 第三方 AI 稿：**搜尋可找到 [EP.125《真正的好朋友（上集）》](https://www.tapesearch.com/episode/ep-125-真正的好朋友-上集/MikMtnKHrx2Fj2S3WizpC8) 及 [SP.2](https://www.tapesearch.com/episode/sp-2-探長會客室/UYfFkrKiBL9EPiggiyP2Se) 等頁面，含時間碼與逐字稿內容。可見內容有把「豬探長」寫成「朱探長」、角色名字不一致及重複片段等問題，不能當成官方校對稿。

Tapesearch 官網列出 Pro 可匯出 TXT、SRT、VTT、JSON；API 方案提供搜尋與 transcript download endpoints，API 文件要求 API key。查核時年繳價格為 Pro US$200／年、API US$720／年，網站標示的月均 US$16.66、US$60 是年費折算，不是這次確認的月繳價格。[方案](https://www.tapesearch.com/)；[API 文件說明](https://www.tapesearch.com/api/access)

**驗證限制：**搜尋／網頁工具可見的是可索引頁面；其中有頁面顯示全文升級提示，但快取時點可能較舊。本機程式直接請求上述兩頁均收到 HTTP 403。本次沒有登入、訂閱或成功下載完整 Tapesearch 逐字稿，因此只能確認「有稿件頁面、業者提供匯出及 API 方案」，尚不能保證豬探長每一集都有可完整匯出的稿。若選此路線，應先確認目標集數覆蓋率，再考慮付費。

**Apple Podcasts：**官方文件目前列出的逐字稿支援語言不含中文／台語，因此不宜把 Apple 的自動逐字稿當作豬探長資料來源。官方所述「下載並編輯逐字稿」是在創作者的 Podcasts Connect；一般聽眾能看稿或複製片段，不等於有他人節目的批次全文下載權限。[Apple 逐字稿說明](https://podcasters.apple.com/support/5316-transcripts-on-apple-podcasts)

**自行轉錄：**對中文豬探長最可控的路線是公開 MP3 → MacWhisper 本機模型 → 匯出 TXT 加 SRT/VTT。MacWhisper 官方確認可匯入 MP3、在本機轉錄並匯出上述格式，也列有批次轉錄功能；模型、方案與執行速度需以實際環境為準。本次沒有啟動轉錄，尚無辨識準確率或處理時間實測。[MacWhisper 官方網站](https://www.macwhisper.com/)

## 後續分析建議

先用豬探長 5 個完整案件、共 10 集驗證流程，再擴大到全系列或跨節目比較。上下集應一起分析，否則會缺少解答、伏筆回收和完整敘事弧線。

建議保留原始音檔與逐字稿，另建分析資料：

| 面向 | 建議欄位 |
|---|---|
| 故事結構 | 開場事件、案件建立、嫌疑人登場、線索、誤導、推理解答、結尾與懸念的時間點 |
| 角色 | 敘事者／角色、角色間關係、對白比例；聲音辨識標籤需人工核對，不能直接當角色名字 |
| 語言與互動 | 語速、句長、重複句型、向孩子提問、等待思考的停頓、難詞 |
| 製作 | 音效、配樂、沉默、場景切換、片頭片尾；這些資訊不能只靠純文字判讀 |
| 內容品質 | 推理是否有充分線索、知識主題、情緒及價值觀；定位與年齡適合度需另外評估 |
| 資料追蹤 | 來源 URL、GUID、抓取日期、SHA-256、轉錄模型及版本、人工修正、音訊與時間碼版本 |

特別注意：同一演員可能配多個角色；背景音樂、誇張聲線及角色名會影響辨識。台語節目需另做辨識品質抽查，不能套用中文樣本的結論。廣告可能隨時間改變，第三方既有稿的時間碼可能對不上本次下載版本。預告、試聽、會客室與完整故事應分開標記。

下載可行性與再利用授權是不同問題。本次只驗證公開內容取得；若之後要重發完整音檔／逐字稿、商業改編或納入模型訓練，應另確認權利與授權，不能僅以免費公開判定。智慧局對 AI 訓練資料也指出，蒐集與訓練可能涉及重製，是否合理使用須個案判斷。[智慧局說明](https://www.tipo.gov.tw/tw/copyright/692-57511.html)
